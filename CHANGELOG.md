# Changelog

## 1.0.2 - 2026-08-12

- Ctrl or Cmd wheel zoom now crosses fit width without flashing or snapping the page
- AND scope mode dynamically hides filter choices that cannot match the current selections
- OR scope mode searches the union of any selected divisions, sections, disciplines, or sources

## 1.0.1 - 2026-08-12

- Zoom buttons and keyboard shortcuts now move in 25% steps
- Ctrl or Cmd plus the mouse wheel zooms in smooth 5% steps
- Mouse-wheel zoom stays anchored beneath the cursor

## 1.0.0 - 2026-08-12

- Virtualized specification viewer with sharp, bounded PDF rendering
- Excel index reconciliation with folder-only and rule-excluded audits
- Division, section, discipline, and source-scoped text search
- Occurrence highlighting, sentence summaries, and smooth keyboard zoom
- Optional lossless combined PDF with contents links and exact return links
- Built-in changelog and full-application update downloads
- Versioned application filenames for every downloaded release
